# Relational Database and Dashboard Preparation

## 📌 Project Overview

This project focuses on designing and analyzing a relational database using **SQL** and creating an interactive **Power BI dashboard** to transform raw data into meaningful business insights.

The project demonstrates data extraction, data manipulation, relational database concepts, and dashboard development for data-driven decision-making.

## 🎯 Objectives

* Design and work with relational database structures
* Perform data analysis using SQL
* Extract meaningful insights from multiple related tables
* Prepare data for visualization
* Create an interactive Power BI dashboard
* Present key business metrics and trends

## 🛠️ Tools & Technologies

* **SQL**
* **Microsoft Power BI**
* SQL Queries
* Data Modeling
* Data Cleaning & Transformation
* Data Visualization
* Dashboard Development

## 🔍 SQL Analysis

The project includes SQL operations such as:

* SELECT and filtering data
* Aggregate functions
* GROUP BY and ORDER BY
* Joins between related tables
* Subqueries
* Business-oriented data analysis
* KPI calculation

## 📊 Power BI Dashboard

The analyzed data was connected to Power BI and transformed into an interactive dashboard.

### Dashboard Features

* Key Performance Indicators (KPIs)
* Category-wise analysis
* Trend analysis
* Comparative analysis
* Interactive charts and visuals
* Filters and slicers
* Business performance insights

## 📌 Key Learnings

* Developed practical understanding of relational databases
* Improved SQL querying and data analysis skills
* Learned how to work with multiple related tables
* Practiced data modeling in Power BI
* Created an interactive dashboard for business reporting
* Learned how to communicate insights through data visualization
